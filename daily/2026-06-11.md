## 2. Self-Replicating AI Worm Uses Open-Weight LLM on Single GPU

### What Happened
University of Toronto CleverHans Lab researchers built a proof-of-concept AI worm using a locally hosted open-weight LLM on a single GPU. The worm autonomously reasons through networks, generates tailored exploit strategies at runtime, replicates itself across hosts, and reached 62% infection on a 33-host network over 7 days without any pre-encoded exploit chain or commercial API dependency.

### Why It Matters
This demonstrates that open-weight models enable autonomous offensive cyber capabilities that bypass traditional patch-based defenses. With no API to revoke and no fixed payload to detect, this represents a fundamental shift in the malware threat model. Preprint on arXiv (2606.03811) is under peer review.

### Key Technical Points
- Open-weight LLM on single GPU, no API dependency
- Average 31.3 vulnerabilities identified per run
- 23.1 hosts elevated access gained (3/4 of targeted)
- Autonomous replication to 20.4 hosts (62% of network)
- Up to 7 generations of self-replication
- GPU-tier replication success rate: 68.8%
- Chained exploits: SambaCry, Dirty Pipe, PrintNightmare, Drupalgeddon 2
- Papernot lab: UofT, Vector Institute, Cambridge, ServiceNow

- Paper: https://arxiv.org/pdf/2606.03811

## 3. Microsoft Open-Source Tools Hacked to Steal AI Developer Credentials

### What Happened
Hackers breached 70+ Microsoft open-source repositories on GitHub, injecting password-stealing malware into code used with AI development tools including Claude Code, Gemini CLI, and VS Code. Microsoft disabled affected repos as Cloudsmith and OpenSourceMalware flagged the Miasma supply chain attack. The malware steals credentials when developers open compromised tools in their AI coding environments.

### Why It Matters
This attack targets the AI developer supply chain at its core — the tools AI developers use daily. With 70+ repos compromised including Azure infrastructure, the blast radius is potentially massive. It follows a pattern of accelerating supply chain attacks against AI infrastructure.

### Key Technical Points
- 70+ Microsoft Azure/AI repos disabled
- Targets Claude Code, Gemini CLI, VS Code users
- Password-stealing malware injected into source
- Attack identified by Cloudsmith and OpenSourceMalware
- Follows similar attacks on Python packages (May 2026)
- Miasma worm propagation to AI coding environments

The paper proves that open-weight models lower the barrier for autonomous offensive cyber capabilities below any previous threshold.
