## 1. Monolithic 3D Silicon Chip Breakthrough at UIUC

### What Happened
A team led by Professor Qing Cao at the University of Illinois Urbana-Champaign demonstrated the first monolithic 3D integration of silicon circuits using standard single-crystalline silicon. The process uses ultra-thin silicon membranes and low-temperature manufacturing to stack multiple transistor layers directly atop one another, overcoming the thermal budget constraint that has blocked true 3D chip production for decades.

### Why It Matters
As transistor miniaturization reaches physical limits, 3D stacking represents one of the few remaining paths to continued compute density scaling. This is especially critical for AI hardware, where monolithic 3D integration could dramatically increase on-chip memory bandwidth and reduce data movement energy — two dominant bottlenecks in AI inference and training.

### Key Technical Points
- Uses standard single-crystalline silicon (not exotic materials), enabling fab compatibility
- Met the thermal budget for monolithic 3D integration for the first time
- Key enabler: ultra-thin silicon nanomembranes with low-temperature processing
- Junctionless transistor design with nanometer-scale vertical interconnects
- Directly applicable to high-performance computing and AI accelerator chips

## 2. GitHub Copilot Switches to Token-Based Billing

### What Happened
Microsoft announced that GitHub Copilot is moving from a flat $29/month subscription to a token-usage billing model. Developers reported potential cost increases from $29/month to as much as $750/month for heavy users, triggering widespread complaints on Reddit and X. The change effectively ends the "golden age" of unlimited AI-assisted coding.

### Why It Matters
This marks an inflection point in AI coding tool economics. The shift to consumption pricing aligns Copilot with the broader industry trend (Snowflake, AI model APIs), but also threatens to price out individual developers and small teams — the very users who drove Copilot's adoption. The backlash highlights the unresolved tension between AI tool providers' unit economics and developer willingness to pay.

### Key Technical Points
- Flat $29/month subscription replaced with per-token billing
- Heavy users report projected costs up to $750/month
- Microsoft had been heavily subsidizing "vibe coding" usage patterns
- Follows broader industry shift toward AI consumption pricing (Snowflake, model APIs)
- Some developers already announcing migration to alternatives

## 4. XCENA Raises $135M for Near-Memory AI Compute Chips

### What Happened
XCENA, a four-year-old chip startup with offices in South Korea and the US, raised $135 million at a $570 million valuation. The company's MX1 chip places compute capabilities directly adjacent to DRAM memory, connected via CXL (Compute Express Link), to eliminate costly round-trips between CPUs, GPUs, and memory during AI inference.

### Why It Matters
XCENA's thesis — that AI inference is increasingly a memory bottleneck problem, not just a compute problem — addresses a fundamental architectural inefficiency. As agentic AI workloads demand sustained, low-latency inference, reducing data movement overhead becomes critical. The CXL-based approach represents an emerging architectural paradigm distinct from both traditional accelerator and in-memory computing approaches.

### Key Technical Points
- MX1 chip connects to CPU via CXL (Compute Express Link)
- Processes data before it leaves the memory module
- Targets AI inference workloads with high random access patterns
- $570M valuation; backed by multiple VCs
- Competes with both traditional accelerators and in-memory compute approaches

## 5. Zig Programming Language Bans AI-Generated Code Contributions

Zig programming language president Andrew Kelley called AI-generated code contributions "invariably garbage" and confirmed that the project's code of conduct bans submitting AI-assisted code. Speaking on the JetBrains podcast, Kelley noted that Zig has 200 open pull requests and that AI-generated submissions waste core maintainer time on valueless review.

As major tech companies project ever-higher percentages of AI-written code, Zig's position highlights the quality-control costs imposed on maintainers. This tension between AI coding tool adoption and open-source project sustainability is likely to intensify as AI-generated PR volumes grow.

# Important Paper of the Day

## Do Language Models Need Sleep? Offline Recurrence for Improved Online Inference

A novel architecture study that introduces a sleep-like consolidation mechanism for transformer-based LLMs. The model periodically converts recent context into persistent fast weights during an offline "sleep" phase using $N$ recurrent passes, then clears its KV cache for efficient wake-time inference. The method shifts computational cost to offline processing while preserving online latency. Tested on cellular automata, multi-hop graph retrieval, and math reasoning tasks, the approach shows that increasing sleep duration $N$ improves performance, with largest gains on problems requiring deeper reasoning. This is highly relevant to agentic AI systems that accumulate context over long horizons.

Link:
https://arxiv.org/abs/2605.26099
