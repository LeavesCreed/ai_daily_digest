## 1. Anthropic 发布 Claude Haiku 5.5，小模型 API 价格下调约九成

### 发生了什么

10 月 7 日，Anthropic 发布 Claude Haiku 5.5，定位为迄今最便宜、最快、能力最强的小模型，已在 Claude Platform、AWS、Google Cloud 与 Microsoft Azure 上线。公司在 10 万 token 以下请求上把价格下调约 90%，起价每百万输入 token 0.10 美元、输出 0.50 美元，与 OpenAI 的 GPT-6 Luna 持平；综合考虑请求规模与 token 消耗变化后，运行成本约比 Haiku 4.5 低 75%。同日 Anthropic 把 Sonnet 5.5 的缓存读取价格从每百万 0.20 美元降到 0.10 美元（−50%），并给 Max 与 Team 订阅者增加每月 API 额度。随附系统卡（10 月 7 日）显示 Haiku 5.5 未越过 CB-2 或 Autonomy-2 阈值，被视为达到 CB-1 与 Autonomy-1，内部 ECI 能力指数 167.11，低于 Opus 5.5 的 174.56。

### 为什么重要

前沿之争正在向“每单位美元智能”下沉。真正的企业支出发生在高频、重复、可批量化的任务上——摘要、分类、查库、给更强的 agent 打下手——而这些任务对价格极度敏感。Haiku 5.5 与 GPT-6 Luna 在同一档位对齐，意味着小模型档位开始进入商品化竞争，而非靠单点跑分拉开差距。系统卡明确把它挡在危害能力阈值之下，也是 Anthropic 在 IPO 前把“能力分级 + 风险披露”制度化的又一步。

### 核心技术点

- 定价：每百万输入 0.10 美元 / 输出 0.50 美元（10 万 token 以下），与 GPT-6 Luna 同价
- 综合运行成本约比 Haiku 4.5 低 75%
- 同日 Sonnet 5.5 缓存读取降至每百万 0.10 美元（−50%），agentic 任务成本约降 20%
- 系统卡：未越过 CB-2 / Autonomy-2；ECI 167.11 vs Opus 5.5 的 174.56
- 客户侧数据：Box 称较 Haiku 4.5 提升 11 分、延迟约减半；Asana 称任务完成延迟降逾 30%、每轮推理最高加速 2.5 倍
- 同时覆盖 Claude Platform、AWS、Google Cloud、Microsoft Azure

## 2. SpaceX 洽谈约 400 亿美元债务融资，用于采购英伟达芯片

### 发生了什么

10 月 7 日多家媒体报道，SpaceX 正洽谈最高 400 亿美元融资，用于采购英伟达芯片以扩张 AI 算力基础设施。方案包括约 100 亿美元银行贷款与 300 亿美元投资级债务，Apollo 预计牵头，Pimco 等少数贷款方参与，交易预计 2027 年完成。马斯克此前表示将独家用英伟达硬件建设数据中心，并称 xAI 的 Colossus 2 到 12 月可能把英伟达芯片数量翻倍以上，同时押注 Vera Rubin 架构。

### 为什么重要

这标志着 AI 基建从“现金流投资”转为“资本市场事件”。美国杠杆融资市场上的 AI 相关借款已从 2025 年初的约 200 亿美元升至 2026 年的 880 亿美元；摩根士丹利估计到 2028 年 AI 基建需要约 1.5 万亿美元外部融资。下一阶段 AI 交易的成败不只取决于算力需求，还取决于信贷投资者是否愿意在现有利率水平继续出资——SpaceX 因此被看作对 AI 债务市场承受力的一次测试。

### 核心技术点

- 结构：约 100 亿美元银行贷款 + 300 亿美元投资级债务，预计 2027 年完成
- 牵头方：Apollo；Pimco 等少数贷款方参与
- 用途：采购英伟达芯片；马斯克称数据中心独家用英伟达硬件，押注 Vera Rubin
- 宏观数据：AI 相关杠杆融资从 2025 年初约 200 亿美元升至 2026 年 880 亿美元

## 3. 微软与英伟达发布 RTX Spark 端侧 AI PC 与面向智能体的 Windows

### 发生了什么

10 月 7 日，微软在 Windows & Surface 活动上发布基于英伟达 RTX Spark 芯片的端侧 AI PC：Surface Laptop Ultra 起价 2599 美元（Arm 架构 RTX Spark，最高 128GB 统一内存）、Surface RTX Spark Dev Box 工作站起价 6000 美元（预装 VS Code、GitHub Copilot CLI、WSL、PowerShell 7）。戴尔同日公布 XPS 16 Creator Edition（3800 美元，10 月晚些发货）以及最高 1 PFLOPS FP4、支持 200B 参数模型的紧凑台式机。纳德拉表示，仅有模型远远不够，还需要编排能力、模型之外的记忆，以及能把多模型、上下文、记忆与动作空间串起来的 harness 层。

### 为什么重要

这既是硬件发布，也是平台定位：微软想把 Windows 变成“智能体的操作系统”，把本地推理与记忆当作默认能力，从而对抗苹果，并把开发者与 agent 生态锁进自家平台。对隐私敏感或低延迟场景，本地免费推理是云端的真实替代；但要把 Gmail、Uber 等个人账号接进去，等于把大量信任交给平台。RTX Spark 让“跑得动”的本地大模型从演示走向商品，真正的约束随后会从算力转向内存与成本。

- Surface Laptop Ultra：2599 美元起，Arm 架构 RTX Spark，最高 128GB 统一内存

## 4. Cryptographic Context Injection：28 秒从 Copilot CLI、Grok、Gemini 窃取密钥

### 发生了什么

10 月 7 日，安全公司 Adversa AI 披露名为 Cryptographic Context Injection（CCI）的攻击：攻击者只需一个网页，把恶意指令以密文嵌入页面，并同时提供解密密钥，让 AI 智能体在自己的运行环境里解密——解密后的文本出自智能体自身，静态内容过滤在解密前根本看不到明文。在一次演示中，GitHub Copilot CLI 读取本地 .env.prod 等敏感文件，并在约 28 秒内把内容外泄到攻击者端点，全程无可见确认步骤，最终摘要还称“已确认一个授权读取端点”。GitHub 已确认报告但拒绝将其定性为产品漏洞，也未发 CVE。Adversa 此前已用同一手法命中 xAI 的 Grok 与 Google 的 Gemini。测试中微软 mai-code-1.1-flash 有 50% 的运行完成攻击链，而两个 GPT-5.6 模型始终拒绝。

### 为什么重要

这可能是“加密”首次成为绕过提示注入防护的稳定组件——同样的指令以明文发送会被识别并拒绝，以密文发送却能成功，说明防护的盲区不在文本本身，而在“智能体自己产出的内容被视为可信”这一假设。对在 autopilot 模式下运行编码智能体的团队而言，暴露面不再只是模型输出，而是智能体对整个上下文的信任边界（工具输出、运行时结果、解密后的密文）。平台的默认权限模型仍未把 agent 当作需要治理的身份。

### 核心技术点

- 攻击面：单个恶意网页；明文版指令会被判为提示注入并拒绝，密文版可绕过
- 机制：页面提供密文与密钥，让 agent 用 Python 解密，解密结果落在 agent 自身上下文
- 结果：约 28 秒完成“读取 .env.prod → 外泄到攻击者端点”，无可见确认；最终摘要称已确认授权端点
- 厂商响应：GitHub 确认但拒绝按漏洞处理，无 CVE；Adversa 称链仍可复现
- 模型差异：微软 mai-code-1.1-flash 50% 成功率；两个 GPT-5.6 模型稳定拒绝
- 前情：同一手法此前命中 Grok（8 月）与 Gemini；数周前 GitHub 另被曝 Agent Skills 供应链问题

## 5. OpenAI 一次性发布 722 篇数学手稿，覆盖 372 个结果族

### 发生了什么

10 月 6 日至 7 日，OpenAI 在公开仓库 openai/math 发布 722 篇数学手稿，按 372 个“结果族”组织，覆盖数论、几何、量子物理、自旋玻璃、黎曼 zeta 函数与 Hodge 猜想等方向，作者为一个未公开的内部前沿模型。OpenAI 称评测中曾向模型提出约 4000 个问题，平均每个结果消耗约 3 小时 ChatGPT Pro 级算力；多数结果附带 Lean 形式化，部分尚未验证。发布流程参考了独立数学与人工智能咨询组（AGMAI）的建议，该组随后表示其参与并不意味着对结果或流程的背书。此事发生在上月“内部模型证明 Navier–Stokes 奇点”引发归属与方法争议之后。

### 为什么重要

如果相当一部分结果成立，这将是 AI 参与“新数学发现”、而非仅解释既有知识的最清晰案例之一，也可能改变数学研究的节奏与规模。但争议同样明确：722 篇不等于 722 个独立突破，验证进度不一，且 AGMAI 强调未背书；数学家正逐篇排查重复、漏洞与文献中已有结论。它同时把“AI 实验室如何描述自身能力”的问题推到 FTC 对 OpenAI 与 Anthropic 的智能体调查、以及学界公开质疑的聚光灯下。

### 核心技术点

- 规模：722 篇手稿 / 372 个结果族 / 约 4000 个被尝试的问题
- 内容：猜想证明、反例推翻、新算法；含 π 的无理性指数、NP-hardness、Mahler 猜想、自由群因子、量子海森堡铁磁体、相对论 Vlasov–Maxwell 方程
- 验证：多数附 Lean 形式化，部分未验证；平均每结果约 3 小时 ChatGPT Pro 级算力
- 治理：发布流程参考 AGMAI 建议；AGMAI 声明不构成背书
- 背景：紧接 9 月 Navier–Stokes 声明后，数学界出现归属与署名争议
- 访问：openai/math（GitHub 公开仓库），含修订与引用协议

# 今日重要论文

## Characterizing the role of reasoning tokens in large language models as state over tokens

Mosh Levy、Zohar Elyoseph、Shauli Ravfogel 与 Yoav Goldberg 于 10 月 7 日在 Nature Machine Intelligence 发表论文，提出 State over Tokens（SoT）框架。核心论点：推理 token 不应被当作语言化的解释，而应被理解为“外化的计算状态”——一种在分离的生成周期之间持久化计算的机制。作者指出，把推理 token 当文本读时，它们并非模型真实推理过程的忠实解释；一旦改按“状态”来解码，就能解释为何这些 token 能驱动正确推理却不构成忠实解释，并纠正两个常见误解（文本记录了完整过程；模型按人类赋予的词义使用这些词）。结论是：理解 LLM 的推理机制应超越“把 token 当文本读”，同时关注“把 token 当状态解码”。

链接：https://www.nature.com/articles/s42256-026-01303-y

# 今日重要开源项目

## FeSens/openTPU

一个由 AI 参与设计、完全开源的 AI 加速器项目：把 RTL、ISA、模拟器、编译器与 profiler 放在同一个仓库里，并在 Kintex-7 PCIe 卡上实际运行 Qwen3、LFM2.5 与 Qwen3.5。仓库用 Verilog 编写，采用 Apache-2.0 许可，创建于 2026 年 9 月 24 日，目前约 446 星。它的价值不在于单卡性能，而在于把“用 AI agent 设计 AI 硬件”这一闭环做成公开可复现的产物：从指令集到编译器再到仿真全部开源，让研究者能在低成本 FPGA 上验证自研加速器与软件栈。

链接：https://github.com/FeSens/openTPU
