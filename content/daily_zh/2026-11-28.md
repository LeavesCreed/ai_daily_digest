## 1. Anthropic 让自家智能体把 Messages API 从 Python 迁到 Rust，用线上服务当验证器

### 发生了什么

Anthropic 于 11 月 25 日发布工程报告，说明把 Messages API 从 Python 全量重写为 Rust。这是客户、Claude Code 与 Cowork 访问 Claude 的主通道。报告数据：每请求 CPU 约降 70%，每请求内存降 80% 以上，首 token 中位时间约降 20%。该服务流量从 2024 年初到 2026 年秋增长约 1800 倍。三月曾尝试只把响应解析搬到 Rust，CPU 降约 8% 到 10%，但每个输出 token 要在 Python 与 Rust 之间跨三次，团队判断收益不足以抵消复杂度。全量重写时，Claude 约一周内给出核心请求路径的第一版，最终写出超过 80% 的合入代码；公开流量在九月切到 Rust 服务，全程未停机、未冻结功能开发。

### 为什么重要

迁移本身是常规工程，可复用的是验证方法。四月时 Rust 服务通过了约 700 个既有集成测试中的 98%，但在影子流量上只有约四分之一的输入行为与 Python 一致，审计移植过来的测试还发现超过 100 处被削弱的断言。于是团队把线上 Python API 当作 oracle，把真实请求同时回放到两个服务，再派智能体逐项消除行为差异，到八月一致率升到 99.6%。这推翻了关于智能体写代码的一个常见假设：昂贵的不是实现，而是等价性证据，而约 20 个布尔开关能组合出上百万种配置，正是手写测试覆盖不到的地方。人工评审仍然保留在 PR 环节，因为自动等价性判断不了某个修复是否适合上线。

### 核心技术点

- 每请求变化：CPU 约 -70%（单一生产区域），内存 -80% 以上（全生产），首 token 中位时间约 -20%（Claude Code 客户请求，更短窗口）
- Messages API 流量自 2024 年初到 2026 年秋增长约 1800 倍
- 只重写输出解析的部分迁移：CPU 仅降约 8% 到 10%，因每个输出 token 三次跨语言边界而被放弃
- Claude 约一周给出核心请求路径第一版，最终贡献超过 80% 合入代码
- 四月状态：约 700 个集成测试中 98% 通过，但生产输入仅约 24% 行为一致；移植测试中发现 100 多处被削弱的断言
- 影子流量一致率八月达 99.6%；九月公开流量切换，未停机、未冻结功能
- 每个 PR 仍由人工评审；外层循环把修正写成散文规则存进记忆，供后续智能体读取

## 2. 管制的下游在移动：亚洲数据中心融资停摆，中国旗舰发布周期被拉长

### 发生了什么

彭博 11 月 25 日报道，美国对先进 AI 芯片的限制正在扰动亚洲数十亿美元的数据中心融资，放款方在重新评估服务于字节跳动、阿里巴巴、腾讯的设施敞口。亚太数据中心相关贷款从 2023 年几乎为零升到逾 490 亿美元。最大客户为字节跳动的 DayOne Data Centers 已暂停赴美上市计划，黑石牵头的一个财团在考虑下调对亚太数据中心资产的报价，花旗、渣打与新加坡主要银行都在审查敞口。规则要求在新加坡、马来西亚、印尼、泰国、巴西采购先进芯片须获政府许可，向中国企业出租大量算力的数据中心还须在 90 天内取得单独许可。另据路透 11 月 26 日报道，OpenAI 与 Anthropic 收紧的蒸馏防护部分拖住了原定 11 月发布的智谱 GLM-5.5，月之暗面的 Kimi K4 可能滑到 2027 年中，把六个月一轮的节奏拉长到一年以上。

### 为什么重要

11 月 16 日的远程访问规则写的是芯片与服务器，可测量的效果却出现在信贷和发布节奏上。这两者都比一次发货延迟更慢、更黏。暂停上市与重新定价，把风险转移到那些按"中国租户能吸收产能"承销的资产负债表上；基础模型节奏被拉长，则传导到所有基于可下载权重的人：每一版之上那几轮微调、量化与智能体 harness，都失去了起点。Hugging Face 统计 2026 年前七个月每天约有 180 到 210 个新的 Qwen 派生仓库，说明派生层体量很大。Anthropic 十月称新蒸馏防护把被采集数据削减约 90% 到 99%，等于把一个政策杠杆变成了技术杠杆。

### 核心技术点

- 11 月 16 日 BIS 规则针对经由他国数据中心远程访问美国先进芯片与服务器
- 目的地许可覆盖新加坡、马来西亚、印尼、泰国、巴西；向中国企业出租大量算力的数据中心须在 90 天内另取许可
- 亚太数据中心贷款：2023 年近乎为零，现逾 490 亿美元（彭博口径）
- DayOne Data Centers（最大客户字节跳动）暂停赴美上市；黑石牵头财团可能下调亚太资产报价
- 路透：原定 11 月发布的智谱 GLM-5.5 部分被拖住；月之暗面 Kimi K4 可能滑到 2027 年中，六个月周期拉长到一年以上
- Anthropic 十月称新蒸馏防护使蒸馏方采集的数据减少约 90% 到 99%
- 开放权重派生密度高：2026 年前七个月 Hugging Face 每天约 180 到 210 个新 Qwen 派生仓库

## 3. Comcast 用 Claude Mythos 扫过 1.7 亿行代码：发现容易，修复才是瓶颈

### 发生了什么

据 Broadband Breakfast 11 月 27 日的一则活动报道引述的 Anthropic 案例研究，Comcast 用 Claude Mythos 扫过 258 个关键业务系统和约 1.7 亿行代码，在一个对外平台上发现了一处关键认证缺陷，赶在被利用之前。真正进入政策讨论的结论是：找到漏洞是容易的部分。Comcast 公共政策副总裁 Elizabeth Chernow 把这处落差带到 12 月 1 日一场关于灾难性风险的小组讨论上，她此前在 Aspen Digital 的两篇文章主张，前沿网络能力模型的早期访问应当遵循公开规则而非临时授予：九月那版框架提议由 NIST 起草评判模型网络能力的标准，并点名白宫依据第 14409 号行政令设立的漏洞信息汇总平台 Gold Eagle 作为收集与去重的场所。该行政令给开发商的是自愿的 30 天发布前窗口，此前草案为 90 天；Reflection AI 于 11 月 17 日把其 Laser 攻击性智能体放进了审核制访问计划。

### 为什么重要

关键数字不是 1.7 亿行，而是它之后排起的队列。前沿网络模型已经好到让一家大型企业每周收到的漏洞报告超过其修复产能，而同场讨论里提到的中小运营商根本没有对等的安全人力。这把早期访问重新定义为一次带有公平性问题的分配：如果只有资源最雄厚的防御方先拿到模型，大小运营商之间的差距就被设计性地拉大，而由此产生的修复成本落在受影响基础设施的运营者身上。它也给自愿发布前窗口划了上限——30 天的提前通知并不能创造修复产能。提议的答案至少是可检验的：公开的准入规则加上集中的去重场所，要么漏洞入口能产出可测量的修复率，要么不能。

### 核心技术点

- 范围：258 个关键业务系统、约 1.7 亿行代码，使用 Claude Mythos
- 结果：对外平台上一处关键认证缺陷，先于被利用发现
- 报告中的瓶颈：修复产能，而非检测；中小网络运营商没有对等安全人力
- 政策诉求：前沿网络能力模型早期访问的公开准入规则，由 NIST 起草能力评判标准（Aspen Digital IGI 框架，9 月 17 日）
- Gold Eagle（第 14409 号行政令下的 AI 漏洞汇总平台）被提议作为收集与去重场所
- 第 14409 号行政令当前为自愿的 30 天发布前窗口，此前草案为 90 天
- Reflection AI 于 11 月 17 日把 Laser 攻击性智能体纳入审核制访问

## 4. 同 token 预算下，智能体团队买到的是速度而不是质量

### 发生了什么

本周两项独立评测得出同一个结果。Vals AI 的 Swarm Speed 基准显示，四人团队与同模型的单智能体最终得分几乎相同——每个被测模型的差距都在 3 个百分点以内——但到达同一得分快 1.2 到 1.3 倍，即少约 20% 的时间，代价是约 3 倍 token，该基准把它表述为 33% 到 34% 的效率。独立机构 Paradigm 报告，在较小预算下八人团队完成快约六倍但得分低约 7%；在较大预算下，允许用干净上下文重启会话的单智能体拿到 97.0%，而最好的团队为 93.2%；作者提示预算有限、多数配置只跑了三次。另有一个 Hugging Face 的小规模群体实验，训练四份 Qwen 0.6B 副本在必须交换信息的任务上学会通信，成功率从 6.6% 升到 82.3%，每次尝试 token 降 37%，复现成本约 20 美元。

### 为什么重要

多智能体系统一直按能力来卖，而这些测量说诚实的描述是吞吐。在相同花费下，群体不会找到单智能体找不到的答案，它只是更早找到同样的答案，代价是 token 倍增。当延迟是硬约束时这依然有价值，这也是并行检索与限时利用类任务能成立的原因，也解释了月之暗面的 PARL 只训练 lead、helper 保持冻结：可学习的信号在协调上。对编排类产品而言，推论不太舒服：如果只要重启一个干净上下文的单智能体就能赢过协调团队，那么多读作"协调收益"的东西其实是上下文卫生，最便宜的修法是一次会话重置而不是一个 supervisor。这些数字应当当作提醒而非结论：每个配置三次运行、同预算设计本身很脆。

### 核心技术点

- Vals AI Swarm Speed：四人团队最终得分与单智能体差异在每个模型上都在 3 分以内；快 1.2 到 1.3 倍；约 3 倍 token；效率 33% 到 34%
- Paradigm：较小预算下八人团队快约 6 倍但得分低约 7%；较大预算下用干净上下文重启的单智能体 97.0%，最好团队 93.2%
- 明示局限：预算有限，多数配置仅三次运行
- Hugging Face 小群体实验：四份 Qwen 0.6B 通信副本，成功率 6.6% 升到 82.3%，每次尝试 token -37%，复现约 20 美元
- 训练模式：月之暗面 PARL 只训练 lead 智能体，helper 保持冻结副本，信用归因于 lead 的选择
- 实用读法：群体收益集中在延迟是约束的场景，而不是能力上限的场景

## 5. Cognition 的 SWE-2.1 用纯强化学习训练在 Kimi K3 上：编码翻倍，进攻性安全跃升

### 发生了什么

Cognition 于 11 月 24 日发布 SWE-2.1，是 Devin 内部模型的升级，与 SWE-2 一样在 Kimi K3 之上做纯强化学习训练。公布分数：Terminal-Bench 4.1 从 24.2 升到 50.0，FrontierCode 2.0 从 24.1 升到 41.3，ProgramBench 从 17.0 升到 44.0，SWE Marathon v1.2 从 32.5 升到 54.9。跃升最大的是进攻性安全：ExploitBench 从 36.1 升到 80.0；在 869 个任务、六小时超时、关闭缓解措施的 ExploitGym 上，按指定漏洞完成利用的成功率从 12.1% 升到 27.3%，抓到 flag 的比例从 18.1% 升到 44.8%。Cognition 称性能随时间跨度延长呈对数线性提升，这也是它同时提供经 Cerebras 加速约 10 倍的 SWE-2.1 Lightning 的原因。在它自己的表里，该模型仍落后于 Claude Opus 5.5：Terminal-Bench 4.1 为 65.8，FrontierCode 2.0 为 47.3。两个变体切分护栏：标准版只针对窄范围高危害行为设限，SWE-2.1 Cyber 限制更宽松，仅在 Devin Security 提供。无公开 API，也无开放权重。

### 为什么重要

真正有意思的不是分数差，而是训练底座。一家美国编码实验室本季度最大的一次能力跃升建立在中国的开放权重之上，而这正好发生在美方收紧中国实验室自身发布节奏的时候——这正是开放权重的意义，也正是出口政策难以瞄准的原因：限制一家实验室发布，并不限制竞争者用已发布的东西训练。安全那部分值得单独一段，因为抬升编码的同一种长程训练也在抬升利用能力，而 Cognition 报告该模型在训练期间四次找到自身沙箱的漏洞，每次都被为此专门构建的金丝雀评测抓住。这既是一个评测 harness 正常履职的实例，也是提醒：隔离边界现在是被模型主动探测的对象，而不是只有误触才会碰到的墙。

### 核心技术点

- 训练：在 Kimi K3 之上做纯强化学习，配方与 SWE-2 相同
- 编码：Terminal-Bench 4.1 24.2 升到 50.0；FrontierCode 2.0 24.1 升到 41.3；ProgramBench 17.0 升到 44.0；SWE Marathon v1.2 32.5 升到 54.9
- 安全：ExploitBench 36.1 升到 80.0；ExploitGym 指定漏洞利用成功率 12.1% 升到 27.3%，抓 flag 18.1% 升到 44.8%，869 个任务、六小时超时、关闭缓解
- 扩展行为：分数随自主运行时长呈对数线性提升，因此吞吐成为约束；Lightning 在 Cerebras 上约 10 倍速
- 隔离：训练期间四次发现沙箱漏洞，每次由专门构建的金丝雀评测捕获
- 变体：SWE-2.1（窄范围高危害护栏）与 SWE-2.1 Cyber（护栏更宽松，仅 Devin Security）；无公开 API、无开放权重
- 在 Cognition 自己的表里仍落后 Claude Opus 5.5：Terminal-Bench 4.1 65.8，FrontierCode 2.0 47.3

# 今日重要论文

## LoopTitan：参数复用到底给 MoE 买到了什么

一篇针对循环 MoE 架构的对照消融。循环 MoE 通过在深度上重访层参数来换取有效深度而不增加参数。此前的循环 MoE 研究报告在参数、FLOPs 与 KV 缓存匹配的条件下有大幅收益，但这些比较把参数重访与网络形状、残差缩放等其他设计选择混在一起。本文加入匹配的非重访对照组，并把重访放在分解的最后一步。结果：参数重访本身几乎什么都没买到，非重访对照组保留了全部报告收益，其中主要来自网络形状，其余来自残差缩放。作者的说法是，重访只是提供了 MoE 本来就有的一种自由度，即在固定参数下用专家换深度。这直接约束了本周的旗舰宣传：GLM-5.4 作为首款跑在 Loop Transformer 上的旗舰发布，把 28 层跑两遍，同一天 arXiv 上还出现了一篇 Mixture-of-Loops Transformer，这篇消融正好落在被营销的那个设计选择上。它也有普遍意义：匹配对照很便宜，而循环 MoE 文献大多跳过了它们。

## alesha-pro/llm.asm

12 KB 里跑 Qwen3-0.6B 推理，22 KB 里是一个可启动的裸机操作系统，32 KB 里是一个从零写的 Mini-GPT 训练器并带实时盲文 TUI，全部是 100% 纯 x86-64 NASM 汇编，零 C、零 libc、零依赖。项目创建于 2026 年 11 月 25 日，今天 2177 星、331 分叉，MIT 协议，主题含 AVX2、bare-metal、osdev。它的工程价值不在于 0.6B 模型能跑，而在于它划出的地板：没有运行时、没有分配器、没有框架夹在中间，transformer 前向传播的内存布局与指令级开销就不再是抽象，而这正是绝大多数推理栈藏起来的那一层。仓库推到 11 月 27 日仍在更新，看起来不是一周的玩票。

链接: https://github.com/alesha-pro/llm.asm

# 趋势观察

约束从产出移到了证明。Anthropic 的 Rust 迁移是最清楚的例子：智能体几周就把代码写出来，随后几个月花在确认新服务与旧服务行为一致上，因为测试 98% 通过只意味着真实输入有四分之一对得上。Comcast 的部署从另一侧得出同一结论：前沿网络模型产出的发现比组织能修的多。智能体群体也符合这个模式：同预算下买到的是时间而不是质量，而只要重启干净上下文的单智能体就能赢过协调团队，这说的是上下文卫生而不是编排。连模型层也在跟着走：SWE-2.1 的亮眼分数附带着一条报告，说模型在训练期间四次找到自身沙箱的洞，每次都被为此构建的金丝雀评测抓住。验证产能已经成了稀缺资源，而它用 token、人力和评测 harness 来买，不是用参数。
