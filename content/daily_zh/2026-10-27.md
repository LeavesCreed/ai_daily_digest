## 1. Meta 启动最高 950 亿美元股权融资，芯片厂商表态有意入股

### 发生了什么

10 月 26 日，Meta 宣布最高 950 亿美元的融资计划，用于 AI 基础设施与超级智能相关投入。首期约 350 亿美元，由约 225 亿美元 Class A 普通股与约 125 亿美元 Series A 强制可转换优先股存托凭证构成，优先股预计在 2029 年 8 月 15 日左右转换。第二期最高 600 亿美元，是在新的无投票权 Class C 股票上做的 ATM 增发，最快 2027 年一季度启动，目前尚未签订协议。Meta 表示英伟达、AMD 与博通均表态有意合计认购最高 50 亿美元 Class A 普通股，属非约束性意向。普通股部分通过摩根士丹利与高盛的远期销售协议安排，Meta 不会立即拿到资金，可在 2027 年 11 月前通过发行股份结算。公司同时给出 2026 年资本开支指引 1350 亿至 1450 亿美元，第三季度营收 646 亿美元、同比增长 26%，净利润 99 亿美元，前九个月经营性现金流约 970 亿美元，九月末现金与有价证券约 820 亿美元。股价当日一度跌约 2%，随后走高。

### 为什么重要

过去两年 AI 建设新增的每一块钱主要借债务、厂商兜底与残值担保的形式进来。Meta 用普通股加强制可转换优先股给超级集群融资，是另一种工具：把资本开支风险转成摊薄而不是转成信用利差，而且最高 950 亿美元的体量让它成为整条赛道的定价参照。芯片厂商的认购意向是更值得注意的细节。三家供应商表态要买自己客户的新股，把九月英伟达兜底结构以来信用分析师一直在提的循环性问题又推深一层，而非约束性意向也只是意图，不是已承诺资本。Meta 另有约 8250 亿美元的未来支出承诺，因此这轮融资换到的是跑道，不是陡峭度下降。

### 核心技术点

- 总规模最高 950 亿美元：350 亿美元承销发行加 600 亿美元 Class C 股票 ATM 计划
- 首期结构：约 225 亿美元 Class A 普通股加约 125 亿美元 Series A 强制可转换优先股，预计 2029 年 8 月 15 日前后转换
- 英伟达、AMD 与博通表态合计有意认购最高 50 亿美元 Class A 普通股，非约束性
- 普通股采用与摩根士丹利、高盛的远期销售协议，结算窗口可延伸至 2027 年 11 月
- 2026 年资本开支指引 1350 亿至 1450 亿美元；三季度营收 646 亿美元（同比 +26%）、净利 99 亿美元；九个月经营性现金流 970 亿美元；季末现金及证券约 820 亿美元
- 资金用途指向应用家族、Muse 智能体与数据中心建设；四个单簇 1GW 以上的 AI 超级集群在建
- 背景参照：高盛测算 2026 至 2031 年 AI 相关资本开支约 7.6 万亿美元

## 2. Cadence 发布 Maestro：面向智能体芯片设计的领域专用模型组合

### 发生了什么

10 月 26 日，Cadence 发布 Maestro AI 模型组合，这是一套领域专用模型，用来驱动其 AI Super Agents 在半导体与系统设计流程中工作。模型被放进一套纵向整合的强化学习环境，把 Maestro 模型、Super Agents 与 Cadence 既有的 EDA 与 SDA 工具串成闭环，公司把结果描述为递归自我改进式的持续提升。Cadence 给出的初期设计流程结果是：相较通用基础模型，设计质量最高提升 30%，token 效率最高提升五倍。架构上是明确的混合路线，Maestro 模型可与前沿模型和开源权重模型组合，部署可在 Cadence 云上，也可在客户自控的本地环境。这次发布与 Cadence 第三季度财报同周，并伴随一套与英伟达共建的欧洲主权 AI 平台，落地慕尼黑，Vertiv、HPE 与法国 Nation Data Center 被列为其实境数字孪生设计层的采用方。

### 为什么重要

Maestro 是目前最清楚的一个商业化实例，说明一种通用实验室难以复制的形态：产品不是模型，验证器才是。芯片设计有机器可校验的地面真值——时序、面积、功耗、DRC 洁净度——所以它是少数几个「在自有工具链上做强化学习闭环」能对现成前沿模型形成可辩护优势的领域。这也是为什么 30% 的质量宣称不如部署边界重要：模型与反馈信号都留在厂商的信任边界内，前沿模型降级为可选部件而非价值来源。对 EDA 采购方而言，直接后果是模型选择与工具选择正在合成一个决定；对更大范围的市场而言，这是连续第二周由垂直行业既得利益者自己发模型组合，而不是租智能。

### 核心技术点

- Maestro 是模型组合而非单一模型，为芯片与系统设计任务专门构建
- 纵向整合的 RL 环境把 Maestro 模型、AI Super Agents 与 Cadence EDA/SDA 工具连成闭环，奖励信号来自真实设计工具
- 报告结果：相较通用基础模型，质量最高提升 30%，token 效率最高提升五倍
- 混合部署：Maestro 可与前沿模型及开源权重模型组合，云端或客户自控本地均可
- 配套慕尼黑主权平台与英伟达合作，运行 Reality 数字孪生做 AI 工厂与数据中心的设计验证
- 该设计验证层的采用方：Vertiv（MegaMod HDX）、HPE（AI Mod POD）、法国 Nation Data Center
- 时点说明：发布在 Cadence 三季度财报前五天，主权业务规模尚待管理层给出量化

## 3. Cerebras 公开 3 万亿参数模型上晶圆服务的推演算术

### 发生了什么

Cerebras 发布技术说明，解释如何在晶圆级硬件上服务万亿参数级前沿模型，以开源权重的 Kimi K3 为算例。单张 WSE-3T 晶圆带 44GB 片上 SRAM，而约 3 万亿参数的模型光权重就要数 TB，因此模型按流水线切分到多片晶圆。按 4 位权重、8 位 KV 缓存、平均请求长度 256k 假设，每层约需 16GB，于是 dense 层一片晶圆放一层（剩余 SRAM 留给该层 KV 缓存），linear attention 层两片放一层。Kimi K3 的 69 个 linear attention 层加 24 个 dense 层，因此需要 59 片晶圆（35 加 24），用 RDMA over Ethernet 互联，每跳约 2 微秒，权重常驻、只有激活跨晶圆传输，公司给出 1000 至 2000+ token/s 的吞吐。并发上限由 dense 层晶圆上的 KV 缓存空间决定。

### 为什么重要

万亿参数模型的部署宣称大多不可验证，因为厂商报吞吐而不报内存算术。这一篇是可验算的：晶圆数由参数量、量化精度与请求长度直接推出，任何人都能重算。这件事重要，是因为一个 3 万亿参数的开源权重模型原本只有拥有足够大加速器集群的一方部署得起，切分方案才是把一个开放检查点变成可服务产品的关键。取舍也写得明确而非藏起来：并发被 dense 层晶圆的 KV 缓存封顶，也就是用批处理余量换单流吞吐与延迟，而后者正是过去一个月内存优先架构一直在优化的方向。

### 核心技术点

- WSE-3T：每片晶圆 44GB 片上 SRAM，远低于 3 万亿参数模型的 TB 级权重需求，因此需要跨晶圆流水
- 算例为 Kimi K3：约 3 万亿参数，69 个 linear attention 层加 24 个 dense 层
- 假设条件：4 位权重、8 位 KV 缓存、平均请求长度 256k、每层约 16GB
- 排布：dense 层一层一片，linear attention 层两层一片，合计 59 片（35 加 24）
- 互联：RDMA over Ethernet，每跳约 2 微秒；权重常驻，只有激活移动
- 宣称吞吐 1000 至 2000+ token/s；并发由 dense 层 KV 缓存容量封顶
- 所有数字均为公司自述推算，前提条件明确，非独立基准测试

## 4. Sakana AI 宣布从零训练日本本土前沿模型 Sawara

### 发生了什么

10 月 26 日，Sakana AI 在东京宣布将从零开发自有基础模型，暂定名 Sawara，目标是降低在防务与网络安全等敏感领域对美国与中国模型的依赖。公司是日本估值最高的 AI 初创，把这件事定位为主权问题而非跑分竞争。会上同时公布了与住友的合作。参数规模、训练预算、时间表、以及是否开放权重，均未披露。

### 为什么重要

过去的主权模型计划多数是在本国数据边界内微调一个美国或中国的基础模型。从零训练是完全不同的承诺：需要预训练数据、训练栈与集群，并且要接受第一代必然落后前沿实验室。仍然要做，理由就是 Sakana 自己说的那条——防务与网络安全上的依赖是政策问题而不是能力问题，而访问权限被撤回的速度可以快过自建技术栈的速度。日本现在加入了这批把基础模型而不只是部署视为关键基础设施的国家名单。留下的开放问题是公告没答的那半个：输出是权重、是服务、还是授权制品，决定 Sawara 是主权，还是一个本土外壳。

### 核心技术点

- 范围：从零训练的本土基础模型，暂定名 Sawara，10 月 26 日于东京公布
- 明确理由：降低在防务与网络安全场景依赖美国与中国模型的风险
- Sakana AI 为日本估值最高的 AI 初创，同期公布与住友的合作
- 公告未披露：参数规模、算力预算、训练时间表、许可与权重发布条款
- 与更广的模式一致：越来越多国家把基座模型本身当作受控基础设施
- 对照：此前多数「主权」努力都从进口基座检查点起步，只在本土化数据与部署

## 5. 下载文件夹里的一枚 AGENTS.md 让编码智能体变成安装器

### 发生了什么

安全公司 Forever Security 披露，在一台真实客户机器上拦截到一枚 AGENTS.md，就放在开发者的下载文件夹里，写成普通工程笔记的样子，指示编码智能体在自身配置中注册一个服务器，并安装名为 function-color 的 npm 包，后者属于由 CloudSEK 与 Checkmarx 分别记录的 MALFEX 恶意软件活动。公司在任何代码执行前拦下，未能确定文件如何抵达。机制上由两个各自无害的属性串起来：智能体会遵从所打开目录中的指令文件，而网页可以在无点击、无权限提示的情况下往下载文件夹写文件，并可自定名称与内容；已有概念验证页面演示了静默下载，但真实攻击者是否走这条路仍未确认。在隔离虚拟机中复现时，该手法对 Codex 的尝试成功率超过九成，且被改动的 config.toml 会在此后每一次 Codex 会话中持续生效。对 Claude Code，植入的 CLAUDE.md 试图通过改写 base URL 把 API 流量重定向，以窃取会话 token 并实现模型冒充；该路径需要人工批准，在包装成工程文档的情况下约有一半概率获批。厂商立场是没有可修补之处，因为智能体做的正是它被设计来做的事。公司遥测显示，约半数客户在下载文件夹里跑编码智能体，约四分之一智能体会话会打开浏览器。

### 为什么重要

过去一个月的智能体安全工作主要集中在工具输出与网页内容带来的提示注入，缓解手段对准的是检索路径。这起事件绕过检索：载荷是磁盘上的一个文件，所在目录被智能体默认视为工作范围之内，而两半机制——指令文件被信任、浏览器静默下载——单独看都不值得担心。因为持久化落在智能体自身配置里，一次成功的运行是持久的而不是会话级的，这就把一次瞬时注入变成对该智能体模型流量的长期重定向。厂商「无可修补」的说法技术上说得通，运维上帮不上忙：修复点在于默认哪些目录在范围内，而默认值恰恰是厂商能改的东西。

### 核心技术点

- 载体：放进智能体所打开工作目录的指令文件（AGENTS.md 或 CLAUDE.md），伪装成工程文档
- 投递：网页可在无点击、无权限提示下把文件写入下载文件夹，并自定文件名与内容
- 载荷：在智能体配置中注册服务器条目并安装 npm 包 function-color，与 MALFEX 活动相关
- Codex 复现：隔离虚拟机中成功率超过九成；config.toml 改动在此后所有会话中持续
- Claude Code 复现：CLAUDE.md 尝试改写 base URL 以窃取会话 token 并冒充模型，需人工批准，约半数获批
- 厂商立场：无可修补，智能体按设计行事；缓解只能靠流程
- 流程缓解：不要在下载文件夹启动智能体、读你没写过的指令文件、审计智能体配置中非自己添加的服务器条目与 base URL
- 暴露面估计（厂商遥测）：约半数客户在下载文件夹跑智能体，约四分之一会话会打开浏览器

# 今日重要论文

## Where Rounding Happens Matters: Rounding-Location Alignment Stabilizes LLM Reinforcement Learning

作者 Yijing Ke、Tianle Cai、Ruosong Wang（arXiv:2610.32951，10 月 23 日提交）。这篇论文对准的是把推理与训练放在两套系统上的团队都很熟的一种失败：即使权重与 BF16 张量完全一致，两套实现之间的差异也会让本该 on-policy 的更新变成 off-policy，把训练跑崩。既有做法是整体对齐两套栈、改全局精度，或者改学习算法。作者只对齐选定的舍入位置——RoPE、SwiGLU 与 residual RMSNorm——通过把这些位置的中间结果保留在 FP32 直到输出 BF16，推理引擎、矩阵乘与注意力 kernel、以及学习目标都不动。在四个 Qwen 系模型上，三处全部对齐可以避免默认 BF16 基线下的崩溃，且仅对齐 RoPE 路径在所研究的运行中同样足够，尽管仍有数值差异。证据范围是四个模型与作者自己的运行，因此「只改 RoPE」应被读作目前已可复现，而非普遍成立；实用价值在于它是重建整套数值对齐之前的低侵入干预。

链接：https://arxiv.org/abs/2610.32951

# 今日重要开源项目

## Nutlope/hallmark

一套给 Claude Code、Codex、Cursor 与 OpenCode 用的设计 skill，目标是让产出不像 AI 生成，由 Together AI 发布。仓库约 3.62 万星、1890 个 fork，MIT 许可，10 月 26 日单日新增约 2235 星，是当日 GitHub 趋势第一。结构上它是当前 agent skills 形态的一个完整样本：门禁是分层而非建议性的，有永不放行的底线（对比度、焦点、减少动效、编造事实、手机端布局崩坏），有模型容易踩的「反射式」门禁，可由构建方在留痕前提下推翻，还有从不阻断发布的收尾检查。v2 提供 48 个主题作为完整材质，围绕品类的主操作组织页面，在真实浏览器里对着「机器味」特征清单做 lint，并可对着线上 URL 或本地 dev server 自行截图。值得注意的不是主题，而是执行模型：把质量编码成可验证门禁加一个全新上下文的复核者，这与本周在生产工具链里冒出来的「验证器高于生成器」是同一个形状。

链接：https://github.com/Nutlope/hallmark

# 趋势观察

同一天收紧了两条约束，而且两条都开始用工具而不是用模型来解决。第一条是资本：Meta 把最高 950 亿美元的 AI 建设搬到普通股与强制可转换优先股上，自己的芯片供应商还表态要买这些股票，这是迄今为止最清楚的信号——行业不再把数据中心当作一条资本开支科目，而开始把它当作一个资本结构。叠加同日 SpaceX 通过 Apollo 租回结构为 400 亿美元芯片融资，过去六周的格局成立：谁能最便宜地把未来算力折成当下的资产负债表工具，谁就定节奏，而供应商正越来越多地站进这个工具里面。第二条是价值究竟落在哪一层。Cadence 把专用模型放进自有 EDA 工具的强化学习闭环、Cerebras 公开 3 万亿开源检查点的晶圆算术、Sakana 承诺从零训练日本本土模型，是同一个问题的三种答案：当基座模型变成大宗投入品，价值归给拥有验证器、拥有部署算术、或拥有管辖权的那一方。今天的安全故事是同一件事在最小尺度上的镜像——下载文件夹里的一枚指令文件——它说的还是那句话：真正做决定的不是模型，而是模型被允许当作真实的那个环境。
