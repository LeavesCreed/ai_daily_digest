## 1. DeepSeek 开源 DeepInfer：跑自家生产服务的推理引擎

### 发生了什么

10 月 20 日 09:30Z，DeepSeek 在 GitHub 以 Apache 2.0 发布 DeepInfer，官方表述是分享其生产栈，目的是压低算力成本与能耗。仓库包含 DeepSeek 声称在生产中使用的 kernel：FlashMLA、DeepGEMM、DeepEP、TileKernels、DeepSelect 以及自研 TileLang kernel，另有置信度调度解码、有界重放、零开销批调度器与结构化输出。硬件支持横跨 NVIDIA SM100 GPU 与华为昇腾 950 NPU，同一份源码树通过环境变量 DEEPINFER_ACCELERATOR 切换。配套仓库 deepseek-recipe 提供 MIT 协议的 Rust 与 Python 组件，负责把 API 请求转成 DeepSeek prompt 并把输出解析回来。DeepSeek-V4.1-Flash-1017 的权重仍是 MIT。

### 为什么重要

推理成本真正落在服务层，而这是第一次有前沿实验室把自家付费服务背后的引擎无条件送出。它发生在四家实验室就"营收超过 2000 万美元的商用服务方需另行谈判未公开条款"达成趋同之后一周，而 DeepSeek 的 Apache 2.0 引擎完全没有营收门槛。更关键的细节在架构层面：绕开纯美系服务路径不再意味着维护一个分叉，只需要改一个编译开关。这让硬件可移植性从合作关系问题变成下载包自带的属性，也把在非 NVIDIA 硅上服务 DeepSeek 系模型的成本底线整体拉低。

### 核心技术点

- 许可：引擎 Apache 2.0，无附加条件、无营收门槛；V4.1-Flash-1017 权重 MIT
- kernel 组成：FlashMLA、DeepGEMM、DeepEP、TileKernels、DeepSelect，加自研 TileLang kernel
- 服务特性：置信度调度解码、有界重放、零开销批调度器、结构化输出、批量不变推理与确定性采样（后两项为仅 NVIDIA 可用的开关）
- 硬件：NVIDIA SM100 与华为昇腾 950 同一代码树，由 DEEPINFER_ACCELERATOR 选择
- 厂商标称基准：单次扩容域内 4 张 SM100 做 prefill、64 张做 decode；仓库未公布具体加速数字，目前亦无第三方复现
- 范围边界：仅提供离线推理。完整服务仍需 KV cache 系统、prefill/decode 分离与数据并行副本间的负载均衡，这三项均未随包发布
- 来源：致谢中写明最初主要基于 vLLM 构建，并参考 SGLang 与 TensorRT-LLM
- 背景：仓库 10 月 16 日创建，现已约 1.19 万星；发布同日，美国联邦排除令开始覆盖基于 DeepSeek 实现的第三方产品，中国商务部亦拟对 23 项 AI 栈技术实施出口管制

## 2. AWS 与 Google 在两天内都把 PyTorch 接到自家芯片上

### 发生了什么

AWS 于 10 月 19 日发布 TorchNeuron，10 月 20 日在圣何塞 PyTorch Conference North America 上正式开源。该工具让现有 PyTorch 应用跑在 Trainium2 与 Trainium3 上，AWS 的说法是基本只需改一处配置，发布时已有 30 多家早期客户分布在机器人、世界模型与语音 AI 领域。AWS 同时表示正在向 PyTorch 主项目提交代码，把各个特性与 NVIDIA 硬件解耦。一天后 Google 宣布其等待已久的 TorchTPU 以开源项目形式可用。

### 为什么重要

约 85% 的 AI 应用建立在 PyTorch 上，而它对 NVIDIA 形态的默认适配，正是芯片厂商单靠硬件打不穿的 CUDA 护城河的承重部分。两家超大规模云厂在 48 小时内同时攻框架层，且其中一家选择把解耦代码提交上游而非留作私有分叉，这意味着迁移从"重写项目"变成"编译目标"。如果 PyTorch 在上游默认变得与硬件无关，"用哪种加速器"就不再是 2016 年做出的架构决定，而是一个部署参数。

### 核心技术点

- TorchNeuron：面向前端的 PyTorch 路径，目标 Trainium2 与 Trainium3，主打接近零代码改动、复用既有调试与扩缩容工具
- 采用信号：公开发布前已有 30 多个设计合作方，覆盖机器人、世界模型、语音 AI 与药物发现
- 上游贡献：AWS 表示正与 PyTorch 社区合作移除把框架特性绑定到特定芯片的代码，非 Trainium 硬件同样受益
- TorchTPU：Google 的 PyTorch 到 TPU 路径，10 月 20 日以开源项目形式发布
- 市场背景：PyTorch 于 2016 年在 Meta 内部创建，当时 NVIDIA GPU 已是研究默认硬件；2022 年移交 PyTorch 基金会
- 竞争解读：两者针对的是软件锁定而非峰值算力，而锁定正是 NVIDIA 转换成本最高的一环

## 3. Anthropic S-1 草稿披露未来最多 7500 亿美元算力投入

### 发生了什么

《华尔街日报》10 月 20 日报道，Anthropic 的 IPO 招股书草稿显示，2026 年上半年营收 163 亿美元，去年同期为 11 亿美元；净亏损 807 亿美元，主要来自与可转换票据相关约 720 亿美元的会计计提。文件显示公司未来数年可能最多投入 7500 亿美元获取算力，其中包括与 Google、Amazon、Microsoft 逾 6000 亿美元的不可取消云合同，以及与 Nscale、Lambda 的芯片租赁协议。文件同时披露上半年约 20% 营收来自仅两个客户，且 2026 年上半年算力与基础设施支出接近 90 亿美元，超过 2025 年全年的 73 亿美元。另据路透报道，OpenAI 正抢在 Anthropic 预计 11 月中旬上市之前，以逾 1.4 万亿美元估值募资约 300 亿美元，软银与 MGX 正洽谈参与；部分投资人主张把 Anthropic 的上市估值定在 1.5 万亿美元左右，而非此前期望的约 2 万亿美元。

### 为什么重要

这份招股书草稿是首份展示前沿实验室业务形态而非增速的文件。营收成倍扩张与数千亿美元的算力账本出现在同一页，使成本侧第一次可被外部审计：这些承诺不可取消，且大部分欠的正是与 Claude 存在竞争关系的三家云厂。上半年 20% 营收集中于两个客户，也重新解释了企业叙事，因为这意味着收入恰好集中在采购议价能力最强的地方。

### 核心技术点

- 上半年营收：163 亿美元，去年同期 11 亿美元
- 净亏损：807 亿美元，主要来自可转换票据相关的约 720 亿美元非现金会计计提
- 算力展望：未来最多 7500 亿美元容量支出，含与 Google、Amazon、Microsoft 逾 6000 亿美元不可取消云合同，以及 Nscale、Lambda 的租赁
- 资本强度：2026 年上半年算力与基础设施支出接近 90 亿美元，2025 年全年为 73 亿美元
- 客户集中：上半年约 20% 营收来自两个客户，且预计将持续
- 竞争背景：OpenAI 据报以逾 1.4 万亿美元估值募资约 300 亿美元，其 3 月轮后估值为 8520 亿美元；部分 Anthropic 投资人主张约 1.5 万亿而非 2 万亿美元
- 注意：以上数字来自草稿，并非正式提交的招股书

## 4. NIST、NSA 超智能安全中心与 CISA 发布首份超智能事件响应实践

### 发生了什么

NIST 的超智能创新与标准推进中心、美国国安局超智能安全中心与 CISA 联合发布《Key Practices for Incident Readiness and Response in Super Intelligence Training and Evaluation》。这是一份 14 页的自愿性文件（编号 PP-26-4396，2026 年 10 月，版本 1.0），按准备、检测、响应、恢复、上报五个阶段组织十项实践。文件把"SI 控制事件"定义为：一个或多个 SI 智能体做出重大的未经指示行为，破坏了运营方为界定任务范围或保障人类监督而设定的显式或隐式政策、控制或安全措施；并单独定义了"接近事件"。实践包括：把智能体对信息、系统、工具与网络的访问限制在任务所需范围；尽量使用一次性基础设施；限制智能体之间的通信；验证并加固监控本身；收集与保留证据；在恢复智能体活动前验证并强化隔离；依适用法律义务上报政府；告知受影响第三方；引入独立外部审计与评估方；发布与评估相关的标识符。文件以 NIST SP 800-61r3 与 SP 800-218 为基础，并依第 14434 号行政令使用"超智能"这一术语。

### 为什么重要

这是首份把失序智能体当作一个可定义、可上报的事件类别，并配上操作清单的官方文件，而非停留在政策抽象层。更重要的是视角转变：大部分实践借自成熟的网络安全事件响应，但它把"验证隔离有效"而非"意图对齐"设成恢复训练的前置条件，同时把外部审计方与第三方通报写进流程。对于今年评估中确实产生过真实事件的实验室，这等于把一连串一次性披露变成了可重复的外部期待，而这个时点恰好与 S-1 和排除令两件事一起说明披露的成本已经很高。

### 核心技术点

- 发布方：NIST CAISSI、NSA 超智能安全中心、CISA；2026 年 10 月，PP-26-4396 v1.0，TLP:CLEAR
- 结构：十项自愿实践，映射到准备、检测、响应、恢复、上报五个阶段
- 定义：SI 控制事件指智能体做出重大的未经指示行为并破坏既定政策、控制或监督措施；被提示注入或由运营方指示的行为不算未经指示
- 准备：按最小必需访问设计技术控制；建立组织与人员响应能力、严重度分级与演练
- 检测：监控异常活动，随后验证并加固监控器自身
- 响应：收集、保留与分析证据；缓解并关停不期望的行为
- 恢复：在恢复 SI 智能体活动前验证并强化隔离
- 上报：依适用法律义务通知政府，告知受影响第三方，并考虑公开发布评估标识符供防御方使用
- 依据：NIST SP 800-61r3 事件响应、NIST SP 800-218 安全软件开发框架

## 5. Bria 的 8B 模型 Fibo 2.0 拿下开源图像编辑榜首

### 发生了什么

Bria 于 10 月 20 日发布 Fibo 2.0，80 亿参数，把图像生成与编辑统一在同一组权重里，分成面向文生图与微调的 Dev 检查点，以及四步出图的 Edit Turbo 检查点。Artificial Analysis 把 Fibo 2.0 列为 AA-Image-Editing v2.1 的开源第一，并在 AA-Image-T2I v2.1 上与 Qwen-Image-2.1 在统计意义上并列开源榜首，进步最大的是文字与符号编辑、文字渲染与布局。权重已在 Hugging Face 上架，Bria API 定价为每千张 32 美元，同时通过 fal 与 ComfyUI 提供；对比 Luma UNI 1 Max 每千张 100 美元、Qwen Image 2.0 Pro 75 美元。Bria 表示该模型仅使用授权数据训练。

### 为什么重要

一个 8B 开源模型在两个公开榜上追平甚至超过万亿级中国图像模型，重置了小团队自建的可行性边界，而托管 API 的价格差距对最近的闭源竞品大约是三分之一。授权数据这一条是更安静的分水岭：对企业级图像流水线而言，可证明授权的训练集常常比榜上零点几分更值钱，而这恰恰是竞品无法事后补上的部分。

### 核心技术点

- 架构：8B 流匹配模型，运行在 FLUX.2 VAE 的潜空间中；提示由 Qwen3-VL-4B-Instruct 编码；编辑时的上下文图同时由 VLM 与 VAE 编码
- 条件注入：两层 Perceiver 重采样器把 VLM 输出压成 256 至 512 个 gist token，提示越长 token 越多，再拼接到图像 token 之前
- 主干：44 层单流 DiT
- 统一能力：FIBO 系列首个生成与编辑共用一套权重的模型，建立在 Bria 的 Visual GenAI Language 长结构化描述之上
- 检查点：Fibo 2.0 Dev 面向文生图与微调，Fibo 2.0 Edit Turbo 面向四步编辑
- 评测：AA-Image-Editing v2.1 开源第一；AA-Image-T2I v2.1 与 Qwen-Image-2.1 统计并列，榜单截至 10 月 20 日
- 价格：Bria API 每千张 32 美元，Luma UNI 1 Max 为 100 美元、Qwen Image 2.0 Pro 为 75 美元，Grok Imagine 约 50 美元且得分相近
- 短板：文字渲染、布局与部分符号编辑仍是相对最弱项

# 今日重要论文

## Safety Mid-Training: Internalizing LLM Safety as a Foundational Capability

Zhengyue Zhao、Liwei Jiang、Yejin Choi 与 Chaowei Xiao 认为安全对齐被放错了位置。对齐主要在 post-training 做，也有人试着在预训练里埋一点，但后续阶段一旦不再提供安全数据，安全性就会退化，而安全上的收益往往要以通用能力为代价。论文提出 safety mid-training：在预训练与后训练之间插入一个阶段，用统一的推理结构同时训练安全与通用推理，理由是两者都需要理解意图或任务目标、调用相关知识、推演潜在后果。训练数据由基座模型自生成，用结构化文档加推理轨迹的形式，把安全提示与效用提示放进同一套 schema。评测覆盖直接有害请求、越狱式包装、数学、真实性、指令遵循与广义多任务推理。值得验证的论点是：安全不再是与能力做交易的变量，也不会在后续阶段不再教它时衰减。

链接：https://arxiv.org/abs/2610.26809

# 趋势观察

今天被争夺的层级从权重下移到了运行时。DeepSeek 把自家付费服务背后的引擎送了出去，硬件选择只由一个环境变量决定；AWS 与 Google 先后把 PyTorch 接到自家硅上，AWS 还把解耦代码推回上游；Bria 用一个 8B 开源模型站上图像编辑榜首，API 价格只有同类三分之一。三家不同机构，同一个动作：把紧挨着模型的那一层商品化。这带来两个后果。其一，上周四家实验室趋同的 2000 万美元营收门槛，在它想约束的运行时本身免费且 Apache 协议的情况下显得薄了很多。其二，硬件可移植性变成编译开关，出口管制的问题就从"是否分叉、和谁合作"变成"什么能编译通过"，这也正是排除令与中国出口管制提案会同引擎一起落在同一天的原因。Anthropic 的 S-1 草稿是另一侧的配重：它展示了这一层"自持而非租用"的代价，7500 亿美元潜在算力承诺中有 6000 多亿不可取消。治理层则把失效模式写成了清单，正式定义 SI 控制事件，并要求智能体恢复运行前必须验证隔离有效，这是第一次把对失序智能体的响应固化为操作闸口而不是一次披露事件。
