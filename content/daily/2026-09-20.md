## 1. Plugin4Shell: Zero-Click RCE Shared by Four Major Coding Agents, Two Still Unpatched

### What Happened
Security researchers at AIR disclosed Plugin4Shell: Claude Code, OpenAI Codex, GitHub Copilot and Google Gemini CLI all hand a marketplace-pinned 40-character commit SHA to git for checkout but never verify that the checkout actually landed on that commit. Because git resolves a ref before a commit object of the same name, an attacker who renames the plugin repository's default branch to the pinned SHA gets the installer to report the expected SHA while executing malicious code. Combined with plugin auto-update, which Claude and Codex both enable by default, the whole chain requires no user interaction. AIR says the flaw was found in May and disclosed to vendors in June, describes it as "the first supply chain vulnerability of the AI agent ecosystem," and reports 925 hijacked in-use skills reaching roughly 134,000 agents. Patch status is uneven: Anthropic fixed Claude Code in 2.1.179 and OpenAI fixed Codex in 0.146.0; Google said it has deprecated Gemini CLI and will not fix it, pointing users to Antigravity; GitHub Copilot remained unfixed at disclosure.

### Why It Matters
This is not another prompt-injection case. It is the first time the plugin and skill distribution layer is confirmed as a standalone attack surface for agentic systems, and its root cause lives in client-side git reference resolution, so no marketplace can remediate it unilaterally. It also shows that ecosystem scale and ecosystem fragility scale together: the default auto-update behaviour added for convenience supplies exactly the zero-click condition. The practical enterprise implication is that restricting plugin sources and auditing repository changes for installed skills is the only mitigation a team can apply on its own before vendors ship fixes.

### Key Technical Points
- Root cause: plugin SHA-pinning bypass — agents pass the pin to git but never verify the checkout landed there
- Exploit condition: attacker controls the plugin repo and names its default branch after the target commit SHA (git prefers a ref over a same-named commit)
- Zero-click mechanic: Claude Code and Codex auto-update installed plugins by default, no developer action required
- Blast radius: AIR reports 925 hijacked in-use skills reaching roughly 134,000 agents, with the agent's own privileges
- Patch status: fixed in Claude Code 2.1.179 and Codex 0.146.0; Gemini CLI deprecated without a fix; GitHub Copilot unpatched
- Mitigation: enterprises can restrict plugin sources and monitor repo changes, but cannot fix the underlying validation logic themselves

## 2. TypeSafe AI Ships Jev, a "System One" Model That Never Talks

### What Happened
TypeSafe AI emerged from two years of stealth with Jev, its first System One model. Rather than generating strings, Jev takes unstructured program state plus a set of typed questions and, through a parallel sampler, returns all answers in a single pass — operations, target elements and calibrated probabilities that software can branch on directly with no parsing or validation step. It is trained with RLCD (Reinforcement Learning for Calibrated Decisions), which optimises probabilities against outcomes rather than human preference. The company claims comparable intelligence to existing LLMs on System One tasks at roughly two orders of magnitude faster and 400x cheaper, with 70–500 ms latency and pricing at $0.042 per million input tokens with output free. Founder Diogo Almeida is a co-inventor of RLHF and InstructGPT; the company has raised $40M led by DCVC. Within days, LangChain and DataCamp published harness integration guides, with LangChain describing Jev as the fast judgement layer inside an agent loop.

### Why It Matters
It reframes the automation gap as an architectural mismatch: most software decisions want one fast, calibrated judgement, not a paragraph of natural language that must be parsed. Using a System 2 chat model for System 1 work systematically inflates both cost and latency. Calibrated probabilities also make confidence operational — thresholds can be set per action according to the cost of being wrong, instead of one global threshold for the whole system. For agent engineering this means lifting fuzzy judgement out of the LLM loop so deterministic code keeps execution authority, while collapsing the token bill to near-noise; the tradeoff is that the model only knows what is placed in the state it is given, so retrieval precision bounds judgement quality.

### Key Technical Points
- Architecture: non-autoregressive LLM with a parallel sampler that emits all outputs in one forward pass, so there is no string generation and nothing to hallucinate
- Training: RLCD, optimising probabilities against outcomes, as distinct from RLHF/RLVR
- Performance and price: vendor-claimed ~200x faster and ~400x cheaper; 70–500 ms; $0.042 per million input tokens, output free
- Output shape: typed decisions with calibrated probabilities, consumable by code without parsing or validation
- Team and funding: founder Diogo Almeida (RLHF/InstructGPT co-inventor), $40M led by DCVC
- Known constraint: the supplied state is the model's only window on the world, so state quality caps judgement quality

## 3. California Orders Agencies to Accelerate Third-Party AI Audits and Floats a Kill Switch

### What Happened
Governor Newsom signed an executive order on Friday directing state agencies to accelerate third-party oversight and independent audits of safety and security risks in AI systems, and to convene national experts to produce new safety recommendations within two months; the accompanying package includes a proposed "kill switch" for frontier models. The order follows his veto of a stricter bill that would have required the largest AI developers to submit to third-party external auditing, build a kill switch and face clearer liability for harm — a measure fiercely opposed by several leading labs. The state's existing tools are the previously signed SB 53 (transparency and incident reporting, defining "materialized catastrophic harm" as potential for 50 or more deaths, chemical or biological weapon release, or more than $1B in damage), SB 813 (the first US framework for certifying independent verification organizations) and AB 1405 (an AI auditor registry with independence standards). On the same day, gubernatorial candidates Becerra and Hilton both declined to commit to Newsom's new safety guidelines.

### Why It Matters
The order replaces the argument over whether to slow down with the question of who produces verifiable evidence. Having used the veto to block mandatory auditing and liability, the state is using executive action to build the audit supply side first, sidestepping legislative deadlock. It dovetails with this week's lab commitments to give external evaluators employee-level access, and it moves the next round of contention into detail: certification standards for verification bodies, audit scope, incident-reporting thresholds, and who holds kill-switch authority.

### Key Technical Points
- Order contents: accelerate third-party oversight and independent audits, convene national experts for recommendations within two months, include a kill-switch proposal
- Preceding veto: a stricter bill requiring third-party auditing, a kill switch and clearer liability was rejected
- Existing state law: SB 53 (transparency and incident reporting; catastrophic harm defined as 50+ deaths, CBW release, or >$1B damage), SB 813 (certifying independent verification organizations), AB 1405 (auditor registry)
- Political reality: candidates Becerra and Hilton did not commit to the guidelines; federally, Trump rejects new constraints
- Open questions: audit scope, certification standards for verification bodies, reporting thresholds, kill-switch authority

## 4. Coordinated Slowdown Sued as Antitrust Violation; Trump Forms "AI Force" and Rejects Constraints

### What Happened
On Friday, paying subscribers to four AI services filed a proposed nationwide class action in the US District Court for the Northern District of California, alleging that Anthropic, OpenAI, SpaceXAI and Google reached an illegal agreement to slow their AI development, violating antitrust law and reducing the value consumers receive for paid subscriptions. The complaint anchors the coordination to September 12, when Anthropic CEO Dario Amodei published an essay urging industrywide cooperation on decelerating frontier progress in exchange for stronger safety measures, and Sam Altman, Elon Musk and Demis Hassabis each publicly agreed the same day; it also points to a July statement signed by senior employees across leading labs acknowledging "intense competitive pressure not to unilaterally slow" development. The plaintiffs say they do not object to companies individually slowing down, only to substituting "collective restraint for individual accountability." Notably, Amodei anticipated the antitrust problem, writing that the US government should mediate "or at least enable" such conversations by issuing "a narrow waiver for certain kinds of safety conversations"; Altman replied that OpenAI welcomes a federal framework with consistent safety requirements but does not need an antitrust exemption or legislation to start. The same day, Trump said on social media that he is forming an AI task force and will appoint an "AI czar," offering scant detail while continuing to reject new guardrails and calling slowdown calls a "conspiracy."

### Why It Matters
The suit forces safety coordination into an antitrust frame for the first time: if coordinated deceleration among frontier labs measurably affects product cadence and subscription pricing, it is indistinguishable from horizontal coordination in any other industry, so any cross-lab safety arrangement must first solve the exemption question. Both the federal and state tracks have now declined to provide that exemption — the White House substitutes an "AI Force" and an AI czar for regulation, while California routes around the legislature with an executive order on audits — leaving labs squeezed between self-certification and litigation.

### Key Technical Points
- Filing: Friday, US District Court for the Northern District of California, proposed nationwide class of paid ChatGPT, Claude, Grok and Gemini subscribers
- Claim: horizontal coordination on slowing development is anticompetitive and degrades value for subscribers
- Key dates: September 12 Amodei essay with same-day agreement from Altman, Musk and Hassabis; July multi-lab employee statement
- Amodei's anticipation: the essay proposed government mediation or "a narrow waiver for certain kinds of safety conversations"
- Altman's response: welcomes a federal framework with consistent safety requirements, sees no need to wait for an exemption or legislation
- Federal posture: Trump announced an AI task force and AI czar while rejecting new constraints, calling slowdown calls a "conspiracy"

# Important Paper of the Day

## When EOS Tokens Disagree: Understanding Length Inflation in On-Policy Distillation (arXiv:2609.20511)

Submitted September 17 by a Microsoft and UNC collaboration, this paper identifies a widely misdiagnosed failure in on-policy distillation (OPD): student responses become excessively long, sometimes exhausting the generation budget, and the culprit is usually not the reward or the data but a termination-token mismatch — base students and post-trained teachers place their stopping probability on different EOS tokens even when their declared stopping sets look identical, which suppresses the student's preferred termination without reliably transferring the teacher's alternative. The authors verify that aligning the decoding stopping set alone is insufficient, while treating functionally equivalent EOS tokens as one shared semantic stopping action substantially mitigates the inflation across Qwen3, Llama and Gemma. In a 400-update K2-Horizon run they also surface a distinct late-stage length inflation that persists after termination alignment, showing the mismatch is important but not exhaustive. An implementation with a five-condition EOS ablation is released.

Link: https://arxiv.org/abs/2609.20511

# Important GitHub Project

## browser-use/jev-ultrafast

A browser-agent reference implementation from browser-use with TypeSafe (created September 16, MIT, roughly 8,300 stars). It replaces a flat action space with a dynamic indexed element table: each observation yields numbered elements, and Jev decides the operation (CLICK, TYPE_TEXT, SELECT, SCROLL_UP/DOWN, WAIT, DONE, BLOCKED) and target index in a single request, invoking a small text model only when the operation is TYPE_TEXT. Two decisions share one network round trip, and only currently supported operations and compatible elements are offered to the model, which removes invalid actions from the policy. The published demo completes a Zurich to London Google Flights search — including actual text generation and loading waits — in 7.1 seconds. Its significance is showing how a System One model can lift the judgement layer out of the LLM loop while keeping an inspectable, deterministic execution path.

Link: https://github.com/browser-use/jev-ultrafast

# Trend Observation

Three threads converge today. First, the trust model of the agent plugin and skill ecosystem has collapsed to the same degree that the ecosystem has scaled: Plugin4Shell shows that distributed SHA pinning was never actually verified on the client, and auto-update turns the flaw into a zero-click attack, while the DeepSeek Harness ecosystem keeps expanding under an "everything is a plugin" architecture — the registry is becoming the next attack surface that needs signing, transparency logs and verifiable builds. Second, governance has split across three tracks: the White House substitutes an "AI Force" and an AI czar for regulation, California uses executive action to bypass legislative deadlock and build audit capacity first, and the judiciary is now asked to decide whether coordinated deceleration is horizontal collusion — making the next fight about who may issue evidence and who bears the cost of not slowing down. Third, the cost structure is being repriced: Jev puts the judgement layer at 400x cheaper and a browser agent finishes a cross-city flight search in seven seconds, implying much of agent inference never needed a frontier chat model, while OpenAI's $278 billion five-year cash gap and Anthropic's pre-IPO release cadence show the frontier end still buys time with capital. Together they make "slowdown" simultaneously a legal question, an accounting question and an architectural choice.
