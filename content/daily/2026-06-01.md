## 1. Microsoft SkillOpt: Agent Skills Become Trainable Parameters

### What Happened
Microsoft Research released SkillOpt (arXiv:2605.23904), a text-space optimizer that treats natural-language agent skill documents as trainable external weights. The system runs a frozen LLM agent through rollout-reflect-edit-validate loops, using a separate optimizer model to propose structured edits to skill documents. Only edits that improve held-out validation performance are accepted.

### Why It Matters
SkillOpt represents a paradigm shift from hand-crafted prompting to systematic skill optimization. Instead of trial-and-error prompt engineering or expensive fine-tuning, agent capabilities can now be optimized through a formal training loop — with the output being an interpretable, portable markdown file. The framework achieved optimal results across all 52 evaluation combinations (7 models × 6 benchmarks × 3 execution environments), including a +23.5 accuracy boost on GPT-5.5 for SearchQA.

### Key Technical Points
- Architecture: Rollout → Reflect (analyze success/failure minibatches) → Edit (add/delete/replace operations) → Validate (held-out gate)
- Treats AGENTS.md and SKILL.md files as external state for frozen agents
- MIT license, 3.1k GitHub stars in first week
- Supported benchmarks: SearchQA, ALFWorld, DocVQA, LiveMathematicianBench, SpreadsheetBench, OfficeQA
- Community already building wrappers: CodexOpt 0.2.0 brings SkillOpt-style optimization to OpenAI Codex

## 2. OpenAI Codex Computer Use Expands to Windows 11

Users can trigger actions via @computer or @Paint commands, and monitor/start tasks remotely through the ChatGPT mobile app on iOS and Android.

Codex moves from being a pair programmer in the sidebar to an operator with its hands on the machine — capable of testing software, hunting bugs, and reviewing documents autonomously. The mobile monitoring capability means agents can work while engineers are away from their workstations.

### Key Technical Points
- Computer Use mode toggled in Codex settings; per-app targeting via @ commands
- Background task execution with mobile supervision via ChatGPT app
- Follows macOS Computer Use launch in April and mobile access in May
- Part of OpenAI's strategy to build a "super app" merging ChatGPT, Codex, and API
- Security: per-app permissions and user-supervised operation model

# Important Paper of the Day

## SkillOpt: Executive Strategy for Self-Evolving Agent Skills

SkillOpt (arXiv:2605.23904, Microsoft Research) introduces a formal optimization framework for agent skill documents. The key insight: a skill document is an agent's "external weight" — since internal weights can be optimized via gradient descent, external weights should have a systematic training method too. The system runs a frozen target model through scored rollouts, uses an optimizer model to propose structured text edits, and gates acceptance on held-out validation improvement. Across 52 evaluation configurations, SkillOpt-trained skills achieved optimal or tied-optimal results. The framework outputs interpretable, portable markdown files — making optimized agent capabilities shareable artifacts rather than proprietary model weights. This paper establishes a new subfield at the intersection of prompt engineering and formal optimization.

Link:
https://arxiv.org/abs/2605.23904

# Important GitHub Project

## microsoft/SkillOpt

SkillOpt (github.com/microsoft/SkillOpt) is the open-source implementation of the SkillOpt framework, released under MIT license. In its first week, the project accumulated 3.1k stars and 300 forks. The repository includes: a full Python training pipeline (skillopt package), pre-built configs for six benchmarks (SearchQA, ALFWorld, DocVQA, LiveMathematicianBench, SpreadsheetBench, OfficeQA), a WebUI for interactive skill training (skillopt_webui), and comprehensive documentation. The codebase is structured for extensibility — new benchmarks and target models can be added via YAML configs. Community adoption is rapid: CodexOpt already wraps SkillOpt for OpenAI Codex users, and the pattern of "train the skill, not the weights" is spreading across agent frameworks.

https://github.com/microsoft/SkillOpt

# Trend Observation

**Agent Skills Become the Atomic Unit of AI Engineering.** The convergence of Microsoft SkillOpt, revfactory/harness, CodexOpt, and the broader GitHub trending data points to a clear paradigm shift: agent skills are crystallizing as the fundamental building block of AI systems. Skills are replacing both monolithic prompts and fine-tuned models as the preferred abstraction — they are portable across model providers, optimizable through formal training loops, and shareable as version-controlled artifacts. This mirrors the evolution from hand-crafted assembly to compiled languages, or from manual server configuration to infrastructure-as-code. The skill layer is becoming the "Dockerfile" of the agent era: a declarative, reproducible, and optimizable specification of AI capability. Combined with Codex's expansion to desktop control, we are witnessing the rapid maturation of agent engineering from artisanal craft to systematic discipline.
