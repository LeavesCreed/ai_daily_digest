## 1. Claude Mythos Preview 在 Project Glasswing 中发现 10000+ 高危0-Day漏洞

### 发生了什么
Anthropic 披露 Project Glasswing 初步成果：Claude Mythos Preview 自4月上线以来，已在系统性重要软件中发现10000+高危/严重漏洞。其中6202个高危/严重漏洞影响1000+开源项目，1726个经确认真实有效。发现 WolfSSL 严重漏洞（CVE-2026-5194，CVSS 9.1）可伪造证书。Mozilla 用 Mythos 在 Firefox 150 中找到271个漏洞，为之前 Opus 4.6 测试的10倍。英国 AI 安全研究院确认 Mythos 为首个完全通过其多步网络攻击模拟的模型。

### 为什么重要
AI 驱动的漏洞发现速度与人类修补能力之比已达结构性不可持续。Anthropic 明确警告发现漏洞比修补更容易构成了重大挑战。Oracle 已因此转为月度补丁周期。这是首个关于前沿模型级漏洞发现的实证数据点，结果显示软件行业当前补丁基础设施无法应对 AI 时代。

### 核心技术点
- 10000+漏洞，6202个高危/严重，1726个确认真实有效
- 关键 CVE：CVE-2026-5194（WolfSSL，CVSS 9.1 证书伪造）
- 英国 AISI：首个完全解决多步网络攻击模拟的模型
- Mozilla：Firefox 150 中发现271漏洞（10倍于 Opus 4.6）
- 某合作银行用该 AI 检测并阻止150万美元欺诈转账
- Mythos 因严重双重用途风险未公开释放
- Anthropic 启动 Cyber Verification Program 面向防御研究者

## 2. DCI：用原始 Shell 命令替代 RAG 降低成本30%并提升准确率

### 发生了什么
多所大学研究者提出直接语料交互（Direct Corpus Interaction, DCI），一种让 AI Agent 绕过嵌入模型、直接使用标准命令行工具（grep, find, sed, head, tail, cat）搜索原始语料的检索范式。两个版本：DCI-Agent-Lite（GPT-5.4 nano，低成本）和 DCI-Agent-CC（Claude Code/Sonnet 4.6，高性能）。在 BrowseComp-Plus 上，用 DCI 替代 Qwen3 语义检索器后，Claude Sonnet 4.6 准确率从69.0%提升至80.0%，API 成本从$1,440降至$1,016。在多跳 QA 上 DCI-Agent-CC 达83.0%，比最强开源权重检索基线高出30.7个百分点。

### 为什么重要
这挑战了向量数据库作为 Agentic AI 默认检索机制的假设。DCI 解决了 RAG 的根本局限：嵌入索引是静态快照，过早过滤掉证据。对于日志、工单、代码提交、事件时间线等动态数据的企业工作负载，DCI 允许 Agent 对工作区的当前状态而非昨天的向量索引进行推理。论文提供了有力实证：对于需要精确定位证据的任务，Shell 级检索优于语义搜索。

### 核心技术点
- DCI 用 Shell 工具（grep, find, sed, head, tail, cat）替代向量嵌入
- DCI-Agent-Lite：GPT-5.4 nano，与使用传统检索的 OpenAI o3 竞争，成本低60%
- DCI-Agent-CC：Claude Code + Sonnet 4.6，多跳 QA 达83.0%（+30.7分）
- BrowseComp-Plus：80.0%准确率（vs Qwen3 检索器69.0%），成本$1,016（vs $1,440）
- 局限：搜索广度超过~10万文档时性能下降，最佳实践为与语义检索混合使用
- 代码以 MIT 许可证发布

### 链接
- 论文: https://arxiv.org/abs/2605.05242
- GitHub: https://github.com/DCI-Agent/DCI-Agent-Lite

# 今日重要论文

## Direct Corpus Interaction (DCI)

发表于 arXiv（2605.05242）。该论文提出 DCI，一种用原始 Shell 命令替代向量数据库的 Agentic AI 检索新范式。DCI 允许 Agent 通过 Shell 管道使用 grep, find, sed, head, tail, cat 直接在原始语料中搜索、过滤和验证信息。在 BrowseComp-Plus 上，DCI + Claude Sonnet 4.6 达80.0%准确率（vs Qwen3 检索器69.0%），API 成本从$1,440降至$1,016。在多跳 QA 上 DCI-Agent-CC 达83.0%，比最强开源权重检索基线高30.7分。论文论证了嵌入索引根本上与需要精确词法匹配、动态数据和迭代假设验证的 Agent 工作负载不匹配。代码以 MIT 许可证发布。

链接:
https://arxiv.org/abs/2605.05242

# 今日重要开源项目

## DCI-Agent-Lite

DCI 的官方 MIT 许可证实现。DCI-Agent-Lite 是轻量级 Agentic 检索系统，由 GPT-5.4 nano 驱动，用原始 Shell 命令替代向量数据库查询。与使用传统检索的 OpenAI o3 竞争，成本约低60%。仓库包含搜索基准测试、多跳 QA 评估、完整 DCI 工具集（基于 grep 的搜索、文件导航、管道组合）。需要更高性能的团队可使用 DCI-Agent-CC 变体（Claude Code + Sonnet 4.6），在复杂搜索任务上达到 SOTA。

# 趋势观察

**AI 驱动的漏洞发现速度已超越人类修补能力。** Anthropic 的 Project Glasswing 数据——一个受限模型一个月内发现10000+漏洞——揭示了未来一年将定义网络安全领域的结构性失衡。补丁周期问题不再是理论：Oracle 已转向月度补丁，Anthropic 明确警告软件行业当前的分类基础设施无法跟上。与此同时，DCI 从向量数据库到 Shell 级检索的范式转变标志着一个成熟的认识：Agentic AI 需要与聊天机器人时代 RAG 根本不同的数据交互模式。这两大趋势的汇聚——AI 作为漏洞发现者和 AI 作为原生 Shell Agent——预示着2026年将更多地由基础设施适应 Agent 工作负载来定义，而非模型能力的单纯进步。
