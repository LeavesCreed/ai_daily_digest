## 1. Anthropic估值9000亿美元，发布Claude Opus 4.8与Dynamic Workflows

### 发生了什么
Anthropic以9000亿美元投前估值完成650亿美元新融资，超越OpenAI的7300亿美元，成为全球市值最高的AI创业公司。同期发布Claude Opus 4.8——距Opus 4.7仅41天——在编程和知识工作方面有显著提升。全新的Dynamic Workflows功能（研究预览阶段）允许大型模型编排数百个并行子Agent，可完成跨越数十万行代码的代码库级迁移。Bridgewater测试者指出Opus 4.8"能主动标记输入输出中的问题，这是其他模型经常忽略的"。Anthropic确认Mythos级模型将在"未来几周内"向所有客户开放。

### 为什么重要
9000亿美元估值——较三个月前的3800亿美元增长2.4倍——反映市场确信编程为核心的AI才是获胜的商业策略。Anthropic营收run rate突破470亿美元，由Claude Code采用推动。Opus 4.8的Dynamic Workflows代表着向Agentic基础设施的具体迈进：前沿模型管理Agent群而非仅生成文本。

### 核心技术点
- Opus 4.8：Agentic编程、推理、金融分析均为最佳水平
- Dynamic Workflows：并行子Agent编排用于代码库级操作
- 改进的不确定性处理：主动标记有问题的输入输出
- Mythos即将面向所有客户开放
- 470亿美元营收run rate，650亿美元新融资

## 2. IBM和Red Hat投入50亿美元启动Project Lightwell保障开源供应链安全

### 发生了什么
IBM和Red Hat宣布Project Lightwell，一项50亿美元的计划，部署2万余名工程师并辅以前沿AI能力，大规模保障开源软件安全。该项目建立可信企业清算中心，利用AI识别、验证和修复开源生态系统中的漏洞。早期采用者包括Bank of America、BNY、Citi、Goldman Sachs、JPMorganChase、Mastercard、Morgan Stanley、RBC、State Street、Visa和Wells Fargo。

### 为什么重要
Project Lightwell直接回应AI加速漏洞发现的军备竞赛。Anthropic的Mythos在开源软件中发现近3900个高/严重漏洞，AI构建的恶意软件VoidLink可在六天内组装完成。IBM的做法——用AI防御而非仅攻击开源供应链——在90%的世界500强依赖开源软件的背景下，代表着结构性的应对措施。

### 核心技术点
- 2万余名工程师辅以前沿AI进行漏洞检测和修复
- 企业清算中心模式：带生命周期管理的验证补丁
- 覆盖Linux、Java、Kubernetes、Kafka、Ansible、Terraform、AI框架、语言工具链
- 整合Anthropic Project Glasswing和OpenAI Trust Access for Cyber的经验
- IBM内部已使用6.2万余个开源包

## 4. Verizon 2026 DBIR记录AI驱动的攻击加速与数据泄漏

### 发生了什么
Verizon 2026年数据泄露调查报告（与Anthropic合作研究）分析了793个威胁行为者，发现中位行为者在15项MITRE ATT&CK技术上使用AI。报告记录了VoidLink——一个AI Agent在六天内组装的恶意软件框架，以及PromptLock——首个利用本地LLM动态生成跨平台加密脚本的AI驱动勒索软件。防御方面，67%的员工在办公设备上使用非企业账户访问AI，源代码是上传到未授权AI服务的首要数据类型。

### 为什么重要
DBIR量化了此前仅凭经验判断的事实：AI将攻击开发周期从数周压缩到数天，同时通过员工AI使用创建新的数据外泄渠道。67%的未授权AI使用率揭示了一个大多数组织甚至无法盘点、更不用说控制的治理缺口。

### 核心技术点
- 793个威胁行为者分析；中位者在15项MITRE ATT&CK技术上使用AI
- VoidLink：AI Agent六天内组装的恶意软件框架
- PromptLock：首个AI驱动勒索软件，动态跨平台加密
- 67%员工未授权使用AI；源代码是第一大泄漏数据类型
- 常规AI用户一年内从15%增长到45%

## 5. RSI正式取代AGI成为AI行业新范式核心

### 发生了什么
递归自我改进（Recursive Self-Improvement, RSI）已成为AI行业新的定义性目标，取代AGI成为存在性辩论和技术野心的焦点。Andrej Karpathy的Auto-Research项目使用Agent群在GPT-2规模上训练LLM进行渐进式自我改进。同期，arXiv新论文"AutoScientists"（2605.28655）展示了自组织Agent团队自主执行长期科学实验，在BioML-Bench的24项生物医学任务中达到74.4%平均排行榜百分位，并发现新的蛋白质结合方法。

### 为什么重要
从AGI到RSI的转变反映了对"AI能否自我改进"比"AI能否像人类一样思考"更具可测量性和深远影响这一认识的成熟。AutoScientists证明Agent团队可以独立发现超越人类设计基线的改进——这是RSI从猜测转向可复现结果的具体里程碑。

### 核心技术点
- AutoScientists：去中心化Agent团队进行长期科学实验
- BioML-Bench 24项任务达74.4%平均排行榜百分位（较最佳单Agent提升8.33%）
- GPT训练优化速度提升1.9倍；发现7项改进而单Agent基为0
- ACE2-Spike蛋白结合预测Spearman相关性提升12.5%
- Karpathy的Auto-Research：Agent群迭代训练GPT-2规模模型

- arXiv (AutoScientists): https://arxiv.org/html/2605.28655v1

# 今日重要论文

## AutoScientists: Self-Organizing Agent Teams for Long-Running Scientific Experimentation

本文提出AutoScientists，一个去中心化多Agent系统，AI Agent可自主提出、执行和迭代科学实验。在BioML-Bench（涵盖生物医学影像、蛋白质工程、单细胞组学和药物发现的24项任务）上，AutoScientists达到74.4%平均排行榜百分位，超越最强单AI Agent 8.33%。在GPT训练优化中，发现改进的速度提升1.9倍，并找到7项优化而单Agent基线为零。在ProteinGym上，发现新的ACE2-Spike结合方法，Spearman相关性较现有最佳提升12.5%。这代表了递归自我改进的具体进展——Agent独立突破人类设计基线。

**编程AI圈地运动多线升级。** 今日新闻群揭示AI编程市场同时发生的三次升级：Anthropic的Opus 4.8 + Dynamic Workflows（规模化Agent编程）、微软的自研Copilot模型（平台独立）以及IBM/Red Hat的Project Lightwell（保护编程AI所消费和生产的开源基础）。三者各自瞄准不同层面——前沿模型能力、平台所有权和供应链完整性——但汇聚于同一现实：代码生成是第一个万亿美元级AI应用，模型提供商、平台厂商和基础设施守护者之间的界限正在消解，融合为单一的竞争空间。
